# Shot Reporter 0.2.0-alpha.12 · Apple build 15

The active report name now follows its Production title instead of the fixed “Current report” label. Edit Production title in Today; the open-report picker, header and saved-report label update immediately. Blank, missing or whitespace-only titles display “Untitled production.” Recently Deleted, delete confirmation and import previews use the same display rule.

This is a presentation change. The original title text stays intact, report IDs/local slots remain stable, and existing records, recovery snapshots, archive formats and export/naming templates are preserved. Editing a production title still creates the normal saved report revision. Local SQLite remains schema 4, complete `.camreport` remains schema 2, and the legacy report-data-only export remains schema 1. The complete archive includes explicitly added files, preferences and recoveries as in build 14.

Validation includes 82 Swift tests, 26 packaging checks, native iOS Simulator production-title rename/restart and Mac return-archive checks, with full model, media, attachment, preference and recovery preservation. Signed Mac UI and real Sparkle upgrade results plus actual TestFlight availability are recorded in the release acceptance files. Physical iPhone UI and AirDrop delivery remain device field checks. Development and verification use disposable synthetic report roots; existing owner reports and trash are preserved. Windows/Android binaries are unchanged.
