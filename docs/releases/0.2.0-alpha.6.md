# Shot Reporter 0.2.0-alpha.6

Shot Reporter now focuses on shot, camera, and script-supervisor reporting.

- Removed the Footage tab, video review, slate-to-clip matching, copy/rename workflows, and naming-template controls.
- Removed bundled video decoders, native RAW helpers, and the desktop media worker.
- Kept project and crew information, scene/shot/take logging, camera settings, flags, circle takes, continuity and editorial notes, report checks, and PDF/CSV/HTML/.camreport handoffs.
- Preserved existing report identities, history, previous snapshots, and legacy archive data. Existing source files and older application data are not deleted or migrated.

## Platform builds

The Mac candidate is version 0.2.0, build 9, for Apple Silicon on macOS 14 or later. Publication requires the exact Developer ID signature, notarization, stapled ticket, Gatekeeper acceptance, and release archive verification. The previous universal Intel-compatible download remains available separately.

The Windows candidate uses MSI version 0.2.2 and a bundled JVM. It remains an unsigned manual installer and may be published only after native Windows CI validates the exact source, actual MSI upgrade, report preservation, and packaged reporting checks. Release assets and validation receipts identify which platform artifacts have passed.

Android and iOS/TestFlight binaries are unchanged. iOS Simulator compilation passed; Android packaging and device instrumentation require their existing toolchain and separate release validation.

## Update delivery and validation

Manual downloads do not activate automatic updates. The Mac application retains authenticated Sparkle checks; the production feed remains inactive until a genuine signed older-to-newer installation, relaunch, and data-preservation check passes. Windows automatic updates remain disabled without trusted publisher/feed configuration.

Local reporting checks include 49 Swift tests, 40 Kotlin tests, 23 packaging tests, native crash recovery, cross-platform archive fixtures, and an isolated Mac demo/take/PDF/relaunch smoke. Two Windows-only tests were skipped locally and must run on Windows before a Windows release. See accompanying release validation receipts for final signed artifact and native CI results.

This remains an alpha. Export independent report backups. The existing no-op edit behavior can advance revision/history on focus changes even when field values do not change; it is unchanged in this release.
