Shot Reporter 0.2.0-alpha.8 brings all responsibilities into one workspace, with no job switches. The sidebar now follows the Squid Productions suite with stacked branding, outline icons, and Settings at the bottom. The lower-left alpha/revision block has been removed.

Camera, media, recording, and lens settings now live in Log. Values carry forward between takes until edited. Editing a recorded setting updates that take and carries the changed value into future takes; earlier takes retain their recorded values. Return to defaults resets future takes to the app’s starting settings without changing recorded takes.

Appearance, Report a Bug, and previous-launch diagnostics are in Settings. Existing reports, recovery snapshots, application identity, and storage remain compatible.

This release updates the Developer ID signed Mac Apple Silicon direct download for macOS 14 or later. Apple marketing version: 0.2.0; build: 11. Other platform downloads and TestFlight builds remain unchanged. Updater-enabled direct Mac installations can use Check for Updates; older copies without updater support require the manual download.

Validation and exact artifact checksums accompany the release. This remains an alpha release; keep independent report backups.
