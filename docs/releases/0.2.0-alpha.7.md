Shot Reporter 0.2.0-alpha.7 removes bundled demo scripts and demo-only workflows. Today starts with New blank report and keeps the existing report picker. Footage and video review remain removed. Existing reports, recovery snapshots, and storage identity are preserved.

The Mac direct-download updater now starts reliably for early manual checks, permits retry after startup failure, distinguishes unavailable feeds and authentication failures, and offers Update Status and View Available Downloads. Normal cancellation and no-new-update results no longer create failure diagnostics. Signed feed and archive checks remain mandatory.

Apple marketing version: 0.2.0; build: 10. Windows MSI version: 0.2.3. TestFlight and App Store builds exclude Sparkle and use their respective update channels. Windows automatic updates remain unavailable without the dedicated trusted publisher configuration and native signed-update acceptance.

Release verification and distribution status are recorded with the release artifacts.
