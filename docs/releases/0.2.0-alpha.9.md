Shot Reporter 0.2.0-alpha.9 adds saved report management and digital Movie/TV reporting.

- Saves now lists saved reports with Delete Report. Confirmed deletion moves a report into Recently Deleted, where Restore Report restores its current and previous snapshots. Other reports and exported files are preserved. Deleting the last report leaves a fresh blank workspace.
- Camera roll / reel is removed from editing, required-field checks, and PDF/CSV/HTML reports. SSD / physical mag and Load ID remain available. Legacy roll values stay in editable .camreport files for compatibility.
- Settings has a per-report Movie/TV switch. Movie is the default and hides Season and Episode in Today and printable reports. TV shows them. Switching modes retains existing season and episode values.
- Repeated focus events with unchanged field values no longer add report revisions or replace the previous recovery snapshot.

Apple marketing version 0.2.0, build 12. The Mac direct download uses the existing Developer ID and authenticated Sparkle channel. iOS and Mac TestFlight builds exclude Sparkle and use TestFlight for updates. The local database advances to schema 2 for recoverable report deletion; portable .camreport files remain schema 1. Older app builds cannot open the migrated local database. Keep report exports and the pre-upgrade backup for recovery.
